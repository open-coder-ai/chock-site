## Agents

Pick one agent per build; the default is __DEFAULT_NAME__. Each policy's label is the catalog's grade for it on that agent; a policy the catalog does not grade there yet says "Not graded yet", never another agent's grade. The selection the builder makes is schema 2 and names the agent in `client`; the share link carries the agent and the policy ids only (`#client=<agent>&p=<id>,<id>`). Read the command before you run it, and ask the user first: it installs hooks that change how their agent behaves.
