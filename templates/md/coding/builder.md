## Agents

Pick one agent per build; the default is Claude Code. Each policy's label is its own grade on that agent. The selection the builder makes is schema 2 and names the agent in `client`; the share link carries the agent and the policy ids only (`#client=<agent>&p=<id>,<id>`). Read the command before you run it, and ask the user first: it installs hooks that change how their agent behaves.
