# chock.sh

The source of [chock.sh](https://chock.sh): a static website for **chock**, a catalog of
policies (guardrails) for AI coding agents. The site lets a visitor browse the policies,
pick the ones they want, and get one `chock install --selection` command that builds a
Claude Code plugin from their picks on their own machine.

The site is generated by a Python script (`sitegen/`) from two pinned inputs:

- `.framework-ref` — the chock engine commit (only `sitegen/engine.py` imports chock);
- `.catalog-ref` — the chock-catalog commit the pages are built from.

It is plain HTML, CSS and vanilla JavaScript: no backend, no third-party requests, no
tracking. There is no deploy command; the local server binds `127.0.0.1` only.

## Local setup and preview (bash)

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pip install "chock @ git+https://github.com/open-coder-ai/chock@$(cat .framework-ref)"
git clone https://github.com/open-coder-ai/chock-catalog .catalog
git -C .catalog checkout "$(cat .catalog-ref)"
python -m sitegen --catalog .catalog --out dist
python -m http.server 8000 -d dist      # open http://localhost:8000
pytest -q                               # unit tests (build the site themselves)
pytest -q tests/e2e                     # browser tests (after: python -m playwright install chromium)
ruff check . && ruff format --check .
```

**One command to build and serve locally:**

```bash
python -m sitegen serve --catalog .catalog            # builds into dist/, then serves http://127.0.0.1:8000
python -m sitegen serve --catalog .catalog --port 8080
```

`serve` runs the same build as `python -m sitegen --catalog .catalog --out dist`, then
serves `dist/` with the standard library's `http.server`, bound to `127.0.0.1` only.
It prints `Serving chock.sh locally at http://127.0.0.1:<port>/ (Ctrl+C to stop)`.
It is a local test server only: there is no deploy command, now or later, in this repo.

## Windows (PowerShell)

```powershell
py -3.12 -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
pip install "chock @ git+https://github.com/open-coder-ai/chock@$(Get-Content .framework-ref)"
git clone https://github.com/open-coder-ai/chock-catalog .catalog
git -C .catalog checkout (Get-Content .catalog-ref)
python -m sitegen serve --catalog .catalog
python -m playwright install chromium
pytest -q tests/e2e
```

## `python -m sitegen` options

- `--catalog PATH`: required. A chock-catalog checkout at `.catalog-ref`; the build
  checks `git -C <catalog> rev-parse HEAD` and exits with code 2 on a mismatch.
- `--out PATH`: required for a build (default `dist` for `serve`). Emptied first, then written.
- `--catalog-source URL_OR_PATH`: default `https://github.com/open-coder-ai/chock-catalog`.
  What the selection's `catalog.source` says. Tests pass the local `.catalog` path.
- `--release vX.Y.Z`: optional. Written to `catalog.release` when given; omitted otherwise.
